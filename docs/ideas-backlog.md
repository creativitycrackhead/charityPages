# Improvement ideas saved for later

Ideas that were proposed and parked. Pick one up by moving it into work.

## Program finder ("Find your first program")

- **Saved:** 2026-10-22
- **What:** A short quiz of about five taps: active volunteers, budget to start, how soon you want to launch, what families need most (food, money, jobs, kids, elders), and time of year (for example, Ramadan coming up). It shows the top 3 matching programs, each with one line on why it fits and a "Start this program" button that feeds into the progress tracker.
- **Where:** Linked from the home page and the Ideas page.
- **Needs:** Nothing new. It uses the scores and the `glance` data (cost, volunteers, launch weeks) already in `assets/ideas.js`, plus a small matching function.

## Announcement kit ("Promote it")

- **Saved:** 2026-10-22
- **What:** On each program page, a form for the masjid's name, date, time, place and contact. It generates (1) a printable one-page flyer in the site's style, (2) a 30-second Jumu'ah announcement script, and (3) a WhatsApp or text message, each with a copy button. Wording follows `docs/style-guide.md`.
- **Needs:** Nothing new. A small template per program (or one generic template using each program's title, tagline and impact line) and print CSS for the flyer.
